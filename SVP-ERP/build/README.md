# Recursos de Compilación (Build Resources)

Esta carpeta está destinada a los recursos gráficos necesarios para empaquetar la aplicación con `electron-builder`.

### Instrucciones para el Icono:
1. Renombra tu icono oficial a `icon.ico`.
2. Colócalo dentro de esta carpeta (`SVP-ERP/build/icon.ico`).
3. El motor de empaquetado lo tomará automáticamente para el ejecutable y el instalador de Windows.

**Nota:** Se recomienda un tamaño de 256x256 píxeles para una resolución óptima en el escritorio.

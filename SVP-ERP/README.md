# SVP ERP Desktop

ERP comercial desarrollado con:

- Electron
- JavaScript
- SQLite

## Ejecución

Instalar dependencias:

```bash
npm install
```

Ejecutar:

```bash
npm start
```

## Crear instalador Windows:

```bash
npm run dist
```

## Características

- POS (Punto de Venta)
- Inventario
- Ventas
- Compras
- Caja
- Facturación
- Reportes
- Multiusuario
- Backup local
